# Rigline – PC gaming website

A static site (HTML, CSS, JavaScript). No build step.

## Publish on GitHub Pages
1. Create a new repository on GitHub.
2. Unzip this folder and upload all files to the repository root.
3. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Your site appears at `https://YOUR-USERNAME.github.io/REPO-NAME/` after a minute or two.

## Edit
- Games and rig tiers: top of `script.js`
- Colors: variables at the top of `style.css`
- News and text: `index.html`
